Where this goes in Square: Site editor → Design → Theme → Colors. Set "Primary" to the navy, "Accent/Buttons" to the coral, and "Background" to the cream — never white. If Square only gives you 2–3 color slots, navy + coral is the non-negotiable pair; cream can be a section background instead of the global one if needed.
Typography — pick from Square's font list

Square doesn't support uploading custom fonts, so match the feel instead of the exact face: a confident serif or script for the Lobsteria name/headers (something with the same nautical-badge character as the logo), and a clean, highly legible sans for menu text and body copy — never let both be the same weight of sans, or it reads generic. In Square's font picker, pair a serif/display heading face with a plain sans body face; avoid anything rounded or playful.

03

Square, step by step

Square Dashboard → Website → Edit Site opens the visual editor. Everything below happens inside it.

1

Set the theme colors first

Do this before touching any page — every section you build after inherits it. Use the four hex values from Section 01.

Edit Site → Design → Theme → Colors
2

Homepage hero

Full-width image + headline + one CTA button. Use the Airstream-at-night shot once you have it (placeholder: your best lobster roll shot until then). Headline: "Miami's Maine Lobster Destination." Button: "View Menu," coral background, links to /menu.

3

Menu preview section

3–4 image tiles: Connecticut Roll, Maine Roll, Oysters, Ceviche. Each links to /menu. Use the new photos here — the oyster platter and ceviche shots are ready right now.

4

About / story section

Short version of Pau's story — Barcelona, La Boqueria, the pandemic pivot, the Airstream. Pull directly from the press release draft or brand bible; don't write it from scratch.

5

Hours, location, map embed

144 NE 27th St, Miami, FL 33137 · Daily 5pm–2am · Walk-up only, free private parking. Embed a Google Map — Square has a native map block, no plugin needed.

6

Sync the menu from Square's Item Library

Don't hand-build the online menu as static text — link it to your existing Square Item Library (the same one your POS uses) so prices and 86'd items stay in sync automatically.

Online → Items → Link to Site Menu
7

Event Boxes / Catering pages

Two dedicated pages already planned in your SEO doc — /eventboxes and /request-catering. Build these as simple: image, description, pricing tiers (18/36/54 rolls), and a contact/order button.

8

Mobile preview before publishing

Most of your traffic is mobile. Use Square's built-in mobile preview toggle on every page — text that looks fine on desktop regularly overflows or overlaps on phone screens in Square's editor.
