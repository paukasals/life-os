01

Project setup

1

Start from a restaurant template, not blank

Webflow's template marketplace has restaurant/food-truck templates built with proper section structure already — search "restaurant" or "food truck" in Webflow Templates. Starting from one saves real time on responsive breakpoints and section scaffolding; you're restyling, not building layout logic from zero.
2

Set up Webflow Variables first

Style → Variables panel
Before touching any page, define your 4 brand colors and 2 fonts as Variables (Webflow's version of design tokens). Every section you build after references these — change a Variable once, it updates everywhere, instead of manually re-editing every section if you tweak a shade later.
3

Point your domain

Project Settings → Publishing
Add lobsteria.co as a custom domain in Webflow, then update your domain's DNS (wherever it's currently registered) to point at Webflow instead of Square. Do this last, only once the site is fully built and reviewed — don't point the live domain at a half-finished site.
02

Typography — real fonts this time

Both available free in Webflow's native Google Fonts picker — no upload needed. This pairing was chosen deliberately: Fraunces has the warmth and slight vintage character that fits a 1977 Airstream without tipping into cliché nautical-script territory; Inter is disciplined and modern enough to keep the whole thing from feeling like a themed restaurant rather than a serious brand.

Display / Headlines
Fraunces
Weight 600–900 for headlines · Italic 500 for pull quotes · Use at 90pt for hero, 32–40pt for section heads
Body / UI
Inter
Weight 400 body copy, 600 for buttons/labels · 16–17pt body, 13pt captions · Never below 13pt on mobile
In Webflow: Site Settings → Fonts → Add Google Font → search "Fraunces" and "Inter" — both are hosted directly by Webflow, no performance penalty. Set Fraunces as your Heading 1–3 default and Inter as your Paragraph/body default in the Style Guide.

04

Menu as a real CMS Collection

This is what Webflow gets you that raw code wouldn't: a Collection is a structured content type you (not a developer) can add/edit items in, with no code touched. It's how the menu grid stays editable without you learning Webflow's design canvas for routine updates.

1

Create a "Menu Items" Collection

CMS → Collections → New Collection
Fields to set up:
NamePlain text
DescriptionPlain text
PricePlain text (e.g. "$30–$42")
CategoryOption: Rolls / Oysters / Ceviche / Add-Ons
PhotoImage
FeaturedSwitch (on = shows on homepage)
2

Populate it once from your master brief

All 6 items are already fully specified in lobsteria-master-brief.md §6 — Connecticut Roll, Maine Roll, Lobster Grilled Cheese, White Truffle Roll, Surf & Turf Roll, Caviar Roll, plus oysters and ceviches. Copy descriptions and prices directly in.
Important — this doesn't auto-sync with Square. Webflow's CMS and your Square Item Library are two separate systems. When a price changes, you'll update it in both places. This is a minor manual step (menu prices don't change often), and it's low-risk: actual checkout still runs through the embedded Square widget below, which always uses Square's live, correct price — the CMS only controls what's displayed, not what's charged.

07

Connecting Square ordering

This is the piece that keeps your POS connection intact — checkout stays on Square, live pricing and inventory included.

1

Get your Square Online checkout link

From Square Dashboard → Online Checkout, or your existing Square Online store URL — this is the actual transaction page, unaffected by moving the marketing site to Webflow.
2

"Order Direct" buttons link out, not embed

Simplest and most reliable: every "Order Direct" button on the Webflow site links directly to that Square checkout URL in a new tab, rather than trying to embed Square's full ordering flow inline (embedding checkout flows cross-domain gets fragile — a clean link-out is more robust and is what most restaurants actually do).
