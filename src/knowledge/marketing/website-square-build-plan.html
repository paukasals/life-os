What Square actually is

⚠️ No custom CSS, no custom HTML layout, no custom fonts beyond Square's curated list. You build by stacking pre-built sections (Hero, Text, Gallery, Product Grid, Form, Newsletter, Map, Embed Code) and editing their content. Everything below is built only from real Square sections — nothing here requires a feature Square doesn't have.
01

Template & theme setup

Do this once, before building any page — it sets the foundation everything else inherits.

1

Confirm you're on an "Order Online" template, not "Shop All"

Template category
Square Online splits templates into two categories: Shop All (retail/product sales) and Order Online (restaurants — menu-forward, built for food ordering). Lobsteria needs Order Online. Check under Site Settings → Template if you're unsure which you're on.
2

Set brand colors in the Style panel

Design → Style
Square gives you a small fixed set of color roles (Primary, Secondary, Background, Button/Accent — exact number depends on the theme). Set them to:
Paste these hex values
Primary: #1B3653 (navy)  ·  Accent/Buttons: #E15C2F (coral)  ·  Background: #FBEEDC (cream — never pure white)  ·  Sparingly (if a 4th slot exists): #D9A441 (gold)
3

Pick fonts from Square's list

Design → Style → Fonts
You can't upload your own font, so match the character instead: choose a confident serif or slab for headings (something with real weight — avoid anything thin or rounded), paired with a plain, highly legible sans for body text and menu items. Don't pick two sans-serifs that look similar — the contrast between the two is what creates hierarchy.

03

Real embed code (for the 2 things that need it)

Square Online has a genuine "Embed Code" section (Add Section → Embed Code) for dropping in third-party iframes/scripts. You only need this for two things — everything else above uses native Square sections.

1. Google Map — exact address, no API key required
<iframe
  src="https://maps.google.com/maps?q=144+NE+27th+St,+Miami,+FL+33137&output=embed"
  width="100%" height="450" style="border:0;"
  allowfullscreen="" loading="lazy">
</iframe>

Only use this if your theme doesn't already have a native Map section — check first, it's simpler and less likely to break.

2. Restaurant/Local Business JSON-LD (already written, from seo-structured-data.md)

This one goes in Site Settings → Custom Code → Header Code, not an Embed Code section — different mechanism, site-wide instead of per-page. Full script is already in your repo, ready to paste.

04

Not possible in Square — don't chase these

Worth knowing upfront so you don't spend time hunting for a setting that doesn't exist.

✕Custom hover animations / lift effects on cardsSquare sections have fixed, theme-defined interactions only.
✕Asymmetric / custom-grid photo layoutsGallery section offers a small set of fixed grid patterns — pick the closest one.
✕Uploading your own font fileChoose the closest match from Square's curated font list instead.
✕Sticky/blurred navigation bar with custom stylingHeader behavior is fixed per-theme; some themes offer a basic sticky-header toggle, most don't.
✕Fully custom page layouts outside the section systemIf you eventually outgrow this, that's a "move off Square" conversation, not a Square settings conversation.
